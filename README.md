# Amber（公开仓库）

这是 Amber 的公开入口：隐私政策、支持说明，以及各产品发布仓的索引。应用源码不在本仓。

## 发布仓

| 产品 | 仓库 |
| --- | --- |
| 桌面应用（Windows / macOS） | 本仓 Releases 中以 `app-v*` 开头的版本（完整公告；Windows ZIP/Setup + macOS DMG） |
| 浏览器扩展（Chrome / Edge / Firefox） | [amber-browser-extension](https://github.com/sumi856/amber-browser-extension) |
| 微信视频号取件 | [amber-weixin-channels](https://github.com/sumi856/amber-weixin-channels) |
| 本地组件（mpv 引擎 / macOS whisper-cli） | [amber-components](https://github.com/sumi856/amber-components) |

视频号、扩展与引擎的旧 Release 已冻结为兼容镜像，供旧版 App 使用；桌面应用每次发版会同步 `app-v*` 完整公告，但不会占用本仓的 `latest`。新版本请到对应产品仓下载。
